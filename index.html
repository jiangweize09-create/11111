📖 操作手册

1导入音频

点左上「＋ 添加音频文件」或直接把文件拖进窗口（可多选）。文件名按 国家_风格_曲目_片段_歌词段_来源 命名会自动识别（如 cn_pop_01_02_01_ai）；识别不对就用画布下方「⚙ 手动修正」改，会写进标注记录。曲库条目右上角 ✕ 可把单曲移出曲库（不动电脑文件、不删已存分数）。

2听歌与打分

每首至少听满 80% 才能保存，进度看标题下「🎧 已听 X%」。在中间画布上点一下情感位置：横轴左消极 → 右积极，纵轴上激动 → 下平静；可按住拖动，也可用方向键微调。点「保存并下一条」或按 S，保存后自动跳到曲库里下一首未标的歌（从上到下顺序）；想随机跳就勾选左上「随机发曲」。

3改分与防误触

已打分的歌再进入会先询问；在打分区再次点击会弹「是否更新评分」，点取消就保持原分。同一首歌永远只保留最新一条，不会出现重复记录。

4填标注人资料

右侧「标注人」面板：姓名、年龄、性别、家乡、MBTI、乐器学习、每天听歌时长、喜欢的音乐风格（可多选）。姓名务必先填——多人标注全靠它区分，不填都算「匿名」。改名前后名字对不上的旧记录，会算在旧名字下（「我的」看不到），在「标注记录」切到「全部」逐条删除即可。资料随每条打分一起导出。

5心理压力（可选）

右侧「心理压力」面板：自己清楚就直接选自评等级、勾选压力来源（学业 / 工作 / 家庭事务等，可多选）；不确定就点「10 题压力自测（PSS-10）」，约 2 分钟出分。做完自动生成一张综合评价表（自评 + 来源 + 得分 + 建议），结果随每条标注一起导出 CSV（stress_ 开头的列）。

6看记录与进度

左下「标注记录」可搜索、修改、删除，点它的标题可以折叠（折叠后曲库列表更长）；顶部进度条和「我的记录」按钮看完成度。列表默认只显示「我的」，点「全部」可看其他人或你改名前的记录。

7导出与备份

右上「⬇ 导出」：CSV（我的记录）只导当前姓名打的分，一首歌一行，Excel 直接打开；多人合作时每人导自己的再汇总，填错名字 / 改名前的旧记录不会被导进来。CSV（全部记录）含所有标注人，每人每歌一行。备份 JSON 用于换电脑。导出会弹「另存为」窗口，自己选文件夹。换设备后用「⬆ 导入标注」还原。

8数据安全

每打一条分立即存到本机浏览器，闪退不丢数据；清浏览器数据或换电脑前记得先导出。全部快捷键按 ? 查看。
